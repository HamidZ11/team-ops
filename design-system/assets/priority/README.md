The five priority glyphs from `src/components/request/glyphs.tsx` on a 14px grid: filled bars in `color-fg-2` (#ababab), empty bars in `color-line-strong` (#333333), No priority dashes in `color-fg-3`, Urgent on `color-danger` with a white mark. Made for dark grounds (`color-canvas` to `color-selected`); the empty bars vanish on light backgrounds. In product code use `PriorityIcon`.
